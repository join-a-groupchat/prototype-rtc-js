=== PROJECT SUMMARY ===

Purpose:
  Real-time communication and message streaming between WebSocket clients,
  Redis (message queue/stream storage), and PostgreSQL (persistent storage).

Key Components:
  1. server.js          - Main WebSocket server handling client connections
  2. server-fanout.js   - Alternative server with fan-out messaging
  3. consumer.js        - Consumes messages from Redis streams, stores in DB
  4. client.js          - Browser-side WebSocket client
  5. Tests/             - Helper scripts for testing Redis, WebSocket, ports

Technologies:
  - Node.js (JavaScript runtime)
  - uWebSockets (high-performance WebSocket server)
  - Redis (in-memory data store & stream processing)
  - PostgreSQL (relational database)
  - Docker (containerization)

Environment Variables:
  - SUPABASE_DB_URL (PostgreSQL connection string)
  - Redis connection (localhost:6379 by default)
  - See .env.example for all variables

Deployment:
  - Docker containers for consumer and server
  - GitHub Actions CI/CD for automated builds and deployment
  - Environment-specific .env files (.env, .env.local, etc.)
